# The First Church of Gravy

A non-prophet organization. Blessed are the drippings, for they shall be poured.

This is the official website of the First Church of Gravy — a single self-contained
page (`index.html`) with no build step and no dependencies beyond Google Fonts.

## Viewing locally

Open `index.html` in any browser.

## Hosting

The site is a single static file, so it can be hosted anywhere — GitHub Pages,
Netlify, or a gravy-adjacent server of your choosing.

*Until the next pour.*
